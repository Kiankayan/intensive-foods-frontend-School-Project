# Intensive Foods – Admin Frontend

An administrative frontend application for the Intensive Foods e-commerce platform, built with React, TypeScript and Vite.

## Overview

The Intensive Foods Admin Frontend provides an interface for managing food products and administrative functionality within the Intensive Foods platform.

The application was developed as part of the Intensive Code Full Stack Developer program, with a focus on modern frontend development, reusable React components and API integration.

## Features

- Administrative interface for managing food products
- Food management interface
- Component-based React architecture
- Type-safe development with TypeScript
- API integration
- Client-side routing
- Form handling and validation

## Tech Stack

- React
- TypeScript
- Vite
- React Router
- Axios
- React Hook Form
- Zod
- Bootstrap

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/Kiankayan/intensive-foods-frontend-School-Project.git
```

Navigate to the application directory:

```bash
cd intensive-foods-frontend/intensive-foods
```

Install dependencies:

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```

Vite will start the development server and provide a local URL in the terminal.

### Build for Production

```bash
npm run build
```
